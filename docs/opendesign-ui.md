# 草根出海产品 UI

本轮按用户确认的 OpenDesign 预览落地到现有 Vue 工作台。品牌 LOGO 继续使用 `frontend/apps/web-antd/public/brand/logo.png`。

## 设计与页面

- 浅灰画布、悬浮玻璃侧栏、白色圆角内容面板、系统蓝与少量 AI 彩色标记。
- 工作台：真实指标圆环、待处理事项、询盘趋势及渠道入口；保留经营分析、客户概览与详细数据。
- 会话与邮件：蓝色选中状态、回复面板、AI 草稿样式；保留账号/等级筛选、窗口限制、内部备注、转交、归档、翻译、附件与客户跳转。
- CRM：保留线索、客户、公海、商机、订单和跟进功能；子模块采用分段导航，表格保留查询、权限、导入导出和列配置。
- AI：统一人设、知识库、技能、话术、转人工与试聊的视觉层级。
- 渠道：现有账号用卡片展示，沿用全部接入、授权、同步与成员分配操作。
- 设置与登录：统一面板、表单、成员和用量视觉；登录继续使用现有认证、租户与验证码流程。

## 数据与权限

设计稿中的客户、消息、金额与在线人数均为演示数据，不随正式界面提交。正式界面读取原接口；没有可用指标时显示缺省状态。现有服务端权限与消息限制保持有效。

## 发布

提交到 main 会触发 GitHub Actions。等待镜像发布成功后再运行 `deploy/install.sh`；需要部署确定版本时，将完整提交 SHA 通过 `CGCH_VERSION` 传入。脚本默认部署 `latest`，它代表最近发布的镜像，可能落后于 main。

数据库和后端接口未在本轮修改。
