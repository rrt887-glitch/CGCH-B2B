# 会话列表与筛选改版

按用户确认的会话原型实现：列表宽度 330px；“我的 / 团队”、账号选择常驻列表顶部；去掉外层重复工具栏；客户等级、群聊与优先级在右侧筛选面板设置；已选条件以可清除标签展示。阅读筛选五项完整显示，无单独横向滚动。

团队入口继续按现有数据权限显示。归属计数标明为全部账号的进行中会话数，账号不展示容易混淆的未读总数。未读角标继续显示在各条会话上。

查询新增 `levels=1,2`、`group=true|false`、`highPriority=true`，在服务端权限范围内、分页前组合筛选。多等级之间 OR，不同条件之间 AND；兼容旧 `level` 参数。筛选不修改客户或会话数据，不需要数据库升级。

验证：前端类型检查、生产打包；真实 Vue 页在本地模拟 API 下检查账号切换、团队查询、筛选请求、清除条件、消息发送和手机返回。CI 加入真实数据库接口检查，覆盖多等级 OR、组合条件、分页总数、旧参数兼容与无效等级拒绝。

部署需等待本提交的 GitHub Actions 镜像发布成功，再使用相应提交 SHA 运行 `deploy/install.sh`。
